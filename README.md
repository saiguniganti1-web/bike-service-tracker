# Bike Tracker: get the APK (no PC tools needed)
1. Make a free account at github.com and create a new repository (any name).
2. Click "uploading an existing file" and drag in EVERYTHING from this folder
   (including the hidden .github folder), then Commit.
3. Open the repo's Actions tab. "Build APK" runs by itself (about 5 minutes).
4. Open the finished run, download "bike-tracker-apk", unzip it, and copy app-debug.apk to your phone.
5. Tap the file and allow "Install unknown apps" when asked.

AI mechanic: the first time you tap Ask, paste your Anthropic API key
(console.anthropic.com). It is stored only on your phone. Everything else works offline.
